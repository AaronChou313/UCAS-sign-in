# 果壳签到本地 Web 版

在浏览器中使用上游 `UCASSignIn.Core`，支持 SEP／轻新课堂登录、多账户、日／周课表、课程目录、学校考勤、手动签到、动态二维码、签到记录、课程偏好和服务端自动签到。首次使用可点击「先体验一下」查看演示数据。

## 运行

需要仓库 `global.json` 指定的 .NET SDK 10.0.303。从仓库根目录执行以下命令，服务在所有网卡的 TCP 17861 端口监听。本机使用 `http://127.0.0.1:17861`，远程设备使用 `http://这台Mac的虚拟组网IP:17861`。

```bash
./run-web.sh
```

脚本优先使用 PATH 中的 `dotnet`，其次使用 `~/.local/share/ucas-dotnet/dotnet`。

macOS 后台服务通过 LaunchAgent 运行。`start` 会先发布应用并在当前用户登录时自动启动，代码更新后再次执行即可重新发布。

```bash
./scripts/web-service.sh start
./scripts/web-service.sh status
./scripts/web-service.sh stop
```

## 使用与数据

- 自动签到由一个总开关控制。课前 29 分钟查询学校状态，未签到时提交，提交后再次核实。未确认成功时每隔 3 分钟重试，上课时停止，确认成功后结束该课次任务。在课前窗口内打开开关会立即检查。服务每 15 秒调度一次，浏览器关闭后仍随服务运行，Mac 睡眠或服务停止时暂停。
- 浏览器课前提醒需要允许通知并保持页面打开。
- 演示模式使用上游虚构数据，签到只在本地模拟。退出演示后恢复已选学校账户。
- 多个浏览器窗口共享同一个本地工作区和当前账户。账户切换后，旧页面的修改请求会提示刷新。
- 今日与日／周课表复用共享核心的排课分组。同一目录课程在日期、时间、教室相同时合并为一张卡片，汇总授课教师。卡片中的「签到明细」保留学校各原始课次 ID 的独立状态、签到与二维码入口；部分记录成功时显示「部分已签到」。
- 会话和选择记住的密码用 ASP.NET Data Protection 加密保存，密钥保存在同机数据目录内。缓存、操作记录和执行记录使用上游文件存储。
- 默认数据目录为仓库 `.local/web/`，访问权限限当前用户。可通过 `UCAS_WEB_DATA` 设置前台运行的数据目录。日志位于 `.local/web/service.log` 与 `service-error.log`。
- 服务支持本机、局域网与虚拟组网 IP 访问。可达此端口的设备共享同一个账户工作区。学校接口由这台 Mac 上的服务调用，前端资源随服务提供。
- 浏览器课前提醒依赖通知权限与安全上下文，远程 IP 的普通 HTTP 页面通常无法使用浏览器通知。
- 账户添加、登录以及真实学校签到需要使用者提供有效学校账号，并能连接学校接口。

## 源码与许可

基于 [WXRIW/UCAS-Sign-In](https://github.com/WXRIW/UCAS-Sign-In)，沿用 AGPL-3.0。对应源码可通过服务的 `/source.zip` 路径下载，其中包含 Web 入口、共享核心、构建配置与启动脚本。

Apple 平台的 iCloud 同步、桌面小组件和原生系统通知仍由上游原生客户端提供。
